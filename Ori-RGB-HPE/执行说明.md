# Ori-HPE 云端执行说明

## 1. 目标

本目录对应云端路径：

```bash
/apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
```

用途是复现一套“官方 X-Fi 结构 + 仅将 RGB 替换为 VK”的公平对比基线。

这里保留了官方主模型、`baseline1`、`baseline2` 三套流程：

1. 主模型：`run.py` + `validate_all.py`
2. baseline1：训练所有单模态/组合模态专家
3. baseline2：读取 baseline1 单模态结果，再做官方 late fusion

## 2. 数据与依赖

默认数据集路径按下面写：

```bash
/apps/users/icps_intelligence/data/lyg/code/MMFi_DATA
```

你还需要提前放好官方 backbone 支撑文件，尤其是：

- `backbones/CSI_benchmark`
- `backbones/depth_benchmark`
- `backbones/lidar_benchmark`
- `backbones/mmwave_benchmark`
- `backbones/RGB_benchmark`

注意：虽然逻辑模态已经改成 `vk`，但数据仍然从磁盘上的 `rgb/` 文件夹读取，并按 `17x2 npy` 解析。

## 3. 推荐执行顺序

如果你要拿这套结果做论文里的公平对比，推荐顺序如下：

1. 训练主模型
2. 验证主模型 31 组合性能
3. 训练 baseline1
4. 生成 baseline2 单模态输出
5. 运行 baseline2 late fusion

## 4. 直接可用脚本

本目录下已经提供了云端辅助脚本，放在：

```bash
cloud_scripts/
```

推荐直接用这些脚本。

### 4.1 主模型训练

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
bash cloud_scripts/01_train_main.sh 0
```

作用：

- 执行 `run.py`
- 使用 `config.yaml`
- 训练主模型

输出：

```bash
pre-trained_weights/checkpoint_*.pth
```

### 4.2 主模型验证

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
bash cloud_scripts/02_validate_main_latest.sh 0
```

作用：

- 自动寻找 `pre-trained_weights/` 下最新的 checkpoint
- 执行 `validate_all.py`
- 输出 31 个模态组合的结果

说明：

- 这个脚本不需要你手动填写 checkpoint 文件名

### 4.3 baseline1 训练

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
bash cloud_scripts/03_train_baseline1.sh 0
```

作用：

- 进入 `baseline1/`
- 自动遍历 `config_all.yaml` 里的 31 个模态组合
- 为每个组合训练一个官方风格 baseline

输出目录：

```bash
baseline1/baseline_weights/
```

典型输出文件：

- `vk_.pt`
- `depth_.pt`
- `lidar_.pt`
- `mmwave_.pt`
- `wifi-csi_.pt`
- 以及多模态组合对应的 `*.pt`

### 4.4 baseline2 生成单模态结果

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
bash cloud_scripts/04_generate_baseline2.sh 0
```

作用：

- 进入 `baseline2/`
- 默认从 `../baseline1/baseline_weights/` 读取单模态权重
- 生成验证集上的单模态预测结果

输出目录：

```bash
baseline2/baseline_results/
```

典型输出文件：

- `vk_result.npy`
- `depth_result.npy`
- `lidar_result.npy`
- `mmwave_result.npy`
- `wifi_result.npy`
- `gt_label.npy`

### 4.5 baseline2 late fusion

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
bash cloud_scripts/05_run_baseline2_fusion.sh
```

作用：

- 进入 `baseline2/`
- 执行 `run.py`
- 直接在终端打印官方 late fusion 的组合结果

### 4.6 一次性顺序跑完

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
bash cloud_scripts/00_run_all.sh 0
```

这个脚本会按顺序执行：

1. 主模型训练
2. 主模型验证
3. baseline1 训练
4. baseline2 单模态结果生成
5. baseline2 late fusion

## 5. 手工命令版

如果你不想用辅助脚本，也可以直接手工执行：

### 5.1 主模型训练

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
CUDA_VISIBLE_DEVICES=0 python -u run.py \
  --dataset /apps/users/icps_intelligence/data/lyg/code/MMFi_DATA
```

### 5.2 主模型验证

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE
LATEST=$(ls -t pre-trained_weights/checkpoint_*.pth | head -n 1)
CUDA_VISIBLE_DEVICES=0 python -u validate_all.py \
  --dataset /apps/users/icps_intelligence/data/lyg/code/MMFi_DATA \
  --pt_weights "$LATEST"
```

### 5.3 baseline1 训练

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE/baseline1
CUDA_VISIBLE_DEVICES=0 python -u run.py \
  --dataset /apps/users/icps_intelligence/data/lyg/code/MMFi_DATA \
  --device cuda:0 \
  --weights-dir ./baseline_weights
```

### 5.4 baseline2 单模态结果生成

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE/baseline2
CUDA_VISIBLE_DEVICES=0 python -u generate_single_result.py \
  --dataset /apps/users/icps_intelligence/data/lyg/code/MMFi_DATA \
  --device cuda:0 \
  --weights-dir ../baseline1/baseline_weights \
  --results-dir ./baseline_results
```

### 5.5 baseline2 late fusion

```bash
cd /apps/users/icps_intelligence/data/lyg/X-Fi/Ori-HPE/baseline2
python -u run.py
```

## 6. 如何切换划分协议

默认是：

```yaml
split_to_use: random_split
```

如果你要切到跨场景或跨被试，需要同时修改下面 3 个文件里的 `split_to_use`：

- `config.yaml`
- `baseline1/config_all.yaml`
- `baseline2/config.yaml`

可选值：

- `random_split`
- `cross_scene_split`
- `cross_subject_split`
- `manual_split`
